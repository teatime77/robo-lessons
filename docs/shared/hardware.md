# 部品・電源・配線の共通仕様

この資料を部品と配線の共通管理場所にします。現時点では機種・型番・電源構成は未選定です。目次に記載した部品名だけで、具体的な配線や通電条件は決まりません。各章の手順を書く前に、下表を実際に使用する部品の一次資料と照合して更新します。

## 選定・確認表

| 部品 | 型番・確認状況 | 手順を確定する前に確認すること |
| --- | --- | --- |
| 単三電池・電池ボックス | 要確認 | 電池の種類、個数、電圧範囲、極性、供給電流、保護、充電可否 |
| DCモーター | 要確認 | 定格電圧、無負荷・負荷・起動・拘束電流、連続運転条件 |
| LED・抵抗・スイッチ | 要確認 | LEDの極性・順方向電圧・許容電流、抵抗値と電力定格、スイッチの定格 |
| ESP32搭載ボード | 要確認 | 正確なボード型番、電源入力、GPIO許容電圧・電流、使用可能なピン、USB給電との関係 |
| モータードライバー | 要確認 | モーター電源と論理電源、信号電圧、連続・ピーク電流、保護機能、制御・停止方式 |
| 距離・ラインセンサ | 要確認 | 電源・信号電圧、インターフェース、測定範囲、配置、校正条件 |
| エンコーダー | 要確認 | 電源・出力形式、測定軸、1回転当たりの計数値、検出エッジ、減速比 |
| IMU | 要確認 | 電源・信号電圧、測定範囲、座標軸、通信と校正方法 |
| サーボ | 要確認 | 電源電圧、動作・起動・拘束電流、信号条件、角度範囲、負荷とトルク |
| USB電源・モバイルバッテリー・ACアダプター | 要確認 | 出力電圧・電流、接続規格、極性、保護、複数電源を使う条件 |
| 車輪・車体・駆動機構 | 要確認 | 車輪径、左右の駆動構成、軸と固定、荷重、接触・巻き込み対策 |

四輪車の基本方針は左右独立駆動です。モーターの個数、接続方法、機構の寸法はここで確定させてから章に反映します。前輪操舵型は別の発展課題として扱います。

## 配線・電源の確認

- 配線を変える前に電源を切ります。電池の短絡、極性、導線の固定、回転部への接触を確認します。
- モーターをESP32のGPIOへ直接つながず、適切なモータードライバーを使います。起動・拘束時の電流も選定条件に含めます。
- LEDは電流制限用の抵抗を使います。電源電圧、LEDの仕様、抵抗値と電力定格を確認してから通電します。
- 電源系と信号系を分けた配線図を作ります。共通GND、信号レベルの変換、USBと別電源の併用が必要・可能かを、対象ボードとドライバーの仕様で確認します。
- 電流測定はテスターの端子・レンジ・定格と測定方法を確認します。電圧測定と同じ接続で電流を測りません。
- 異常な発熱や動作があれば通電を止め、電源を切って配線と定格を確認します。

この資料は具体的な型番を確認した配線図の代わりにはなりません。未確認の仕様を推測して通電しません。

## 型番確定時の記録

部品ごとに次を記録し、章と講師資料から参照します。

1. 英語の安定した識別子、メーカー、正確な型番・基板リビジョン。
2. メーカーのデータシートURL、版、確認日、必要な定格と使用条件。
3. 電源電圧・電流・極性、使用ピン、信号条件、停止方法。
4. 配線図・CAD・部品表の編集元と公開用データの場所。
5. 仕様値と別に、実測結果・測定条件・差し替え部品での違い。

共通仕様を更新するときは、影響する章、サンプルコード、ファームウェア、配線図、講師用・生徒用資料を同時に照合します。
