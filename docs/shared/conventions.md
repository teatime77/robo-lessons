# 用語・記号・単位の共通ルール

各章で必要な説明は短く残し、同じ用語・記号はこの資料に合わせます。前提知識を示し、入門・基本・発展の課題を選んで進めます。学年や年齢だけで課題を決めません。

## 言葉と値の種類

| 用語 | この教材での使い方 |
| --- | --- |
| 位置 | 原点と座標軸に対する場所。進んだ道のりとは区別する |
| 移動距離・道のり | 軌跡に沿って進んだ長さ。往復しても増える |
| 変位 | 終点の位置から始点の位置を引いた量。方向や符号を持つ |
| 速さ | 移動の速さを表す非負の量 |
| 速度 | 方向や符号を持つ量。直線上なら位置の時間変化 |
| 加速度 | 速度の時間変化。減速時の符号は座標軸による |
| PWM指令値 | ドライバーへの指示。速度そのものではない。一定の指令値は一定速度を保証しない |
| 車輪から推定した距離 | 車輪径と回転量から求めた値。滑り、車輪径、計数方法の誤差を含む |
| 実測値 | 実際に測定した値。測定器、条件、日時、繰り返し、ばらつきを記録する |
| 理論値 | 明示した法則・モデル・仮定から計算した値 |
| シミュレーション値 | 明示したモデル・パラメータ・数値計算法から得た値 |
| 説明用の仮定 | 説明のために設定した条件や値。実機の仕様・実測値として扱わない |

エンコーダーで実測したパルス数と、その値からモデルで推定した移動距離は分けて記録します。予想の根拠にも、実測・計算・仮定のどれを使ったかを書きます。

## 記号と単位

基本の記号を次のように使います。別の意味で使う必要がある場合は、その章と図表内で定義し直します。

| 量 | 記号 | 計算時の基本単位 |
| --- | --- | --- |
| 時間、時間間隔 | $t$, $\Delta t$ | $\mathrm{s}$ |
| 移動距離、位置 | $d$, $x$ | $\mathrm{m}$ |
| 速度、速さ | $v$, $\lvert v\rvert$ | $\mathrm{m/s}$ |
| 加速度 | $a$ | $\mathrm{m/s^2}$ |
| 車輪の半径、直径 | $r$, $D$ | $\mathrm{m}$ |
| 角度、角速度 | $\theta$, $\omega$ | $\mathrm{rad}$, $\mathrm{rad/s}$ |
| 回転数（回転の合計） | $n$ | 回（無次元） |
| 回転速度 | 記号は各章で定義 | $\mathrm{rev/s}$。rpmを使う場合は明記 |
| エンコーダーの計数値 | $N$ | カウント（計数方式を明記） |
| 質量、力、トルク | $m$, $F$, $\tau$ | $\mathrm{kg}$, $\mathrm{N}$, $\mathrm{N\,m}$ |
| 電圧、電流、抵抗 | $V$, $I$, $R$ | $\mathrm{V}$, $\mathrm{A}$, $\Omega$ |

- 値と単位の間に空白を入れます（表記の例：`10 mm`。実測値ではありません）。表・グラフの列名や軸にも単位を書きます。
- 工作ではmm、授業ではcmを使えます。計算の前に単位をそろえ、変換を示します。
- 角度は授業やサーボ指令では度を使えます。三角関数・微分・積分の計算ではradを基本にし、変換を明記します。
- PWMの範囲、符号、%と整数の対応は実装ごとに定義し、速度の単位を付けません。
- 減速比は「どちらの回転速度をどちらで割るか」を式で定義します。パルス数は検出エッジ、逓倍、測定軸、減速機の位置を記録します。

例として、直線上の平均速度は次のように表せます。$x_1,x_2$ は時刻 $t_1,t_2$ の位置であり、往復した道のりを使う平均の速さとは区別します。

$$
\bar{v} = \frac{x_2 - x_1}{t_2 - t_1},\qquad t_2 > t_1
$$

## 座標軸と符号

車体座標は原点を図で指定し、$x$ を前、$y$ を左、$z$ を上とする右手系を基本にします。$z$ 軸まわりの正の回転は上から見て反時計回りです。世界座標の原点と向きは実験ごとに図で示します。

モーター・エンコーダーの正方向は「車体が前進する向き」に合わせて校正し、左右で配線や符号処理が違う場合は記録します。カメラ画像の右向き・下向きの座標や、IMUの部品固有の軸は車体座標と分け、変換を説明します。

## 図・数式・参照

- 図には日本語の説明、キャプション、代替説明を付けます。測定条件、軸、単位、値の種類を読み取れるようにします。
- 数式には使う量、仮定、適用範囲を書きます。近似的な等速運動と厳密な等速モデルを区別します。
- 図・動画・アニメーションからの観察は、数学的な証明と区別します。シミュレーションの一致だけで実機や全条件での成立を主張しません。
- 本文・図・式には内容に基づく英語識別子を使います。章の順序が変わっても維持します。
- 未公開の数学・物理教材へのリンクは置かず、この教材内で必要な説明と前提を示します。
