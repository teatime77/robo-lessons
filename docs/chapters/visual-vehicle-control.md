# 第4章　ビジュアルプログラミングで四輪車を走らせよう

## 問いと到達目標

左右のモーターに何を指示すれば、前進・後退・旋回ができるでしょうか。動作をブロックの組合せで表し、繰り返しと停止を使ってコースを走ります。

## 前提知識と関連する章

{ref}`visual-motor-control` の順次実行と {ref}`four-wheel-assembly` の左右駆動を使います。実施前に {ref}`practice-readiness` の停止・走行範囲の確認を行います。

## 必要な部品・工具

組み立てた四輪車、確認済み電源とブロック環境、PCまたはスマートフォン、コースを示すテープ、定規を使います。左右モーターの正方向を共通仕様に記録します。

## 学ぶこと

### 左右の組合せと旋回

左右とも前進方向なら前へ進み、左右とも逆方向なら後退します。左右の進む速さが異なると曲がります。左右を反対向きにする旋回もありますが、実機では横滑りや大きな負荷が生じる場合があるため、確認済みの低い指令で扱います。

「左右に同じ指令」と「左右が同じ速さ」は別です。モーター、摩擦、荷重、電源に違いがあり、同じプログラムでも軌跡が変わる可能性があります。この段階では時間と指令を調整する開ループの操作を使います。

### 繰り返しと動作のまとまり

何度も同じ手順を書く代わりに、「前進→停止」の組を繰り返します。繰り返す範囲と回数を明示すると、変更する場所が少なくなります。「前進」「左旋回」をまとまりとして考える経験は、後の関数につながります。

## 予想

右側の進み方を左側より大きくすると、どちらへ曲がるでしょうか。同じコースを同じプログラムで走れば、毎回同じ位置へ着くかも予想します。

## 工作・配線・プログラミング

1. 車輪を浮かせて左右の方向を確認し、前進の指令を統一します。
2. 床の走行範囲を確保し、前進・停止だけの短いプログラムを作ります。
3. 後退と旋回を別々に試し、動作名と左右の指令を表にします。
4. 次の疑似コードをブロックへ置き換えます。

```text
決めた回数繰り返す：
    前進する → 決めた時間待つ → 停止する
    左に曲がる → 決めた時間待つ → 停止する
最後に停止を確認する
```

5. 動作の時間を一つずつ調整し、停止した場所を記録します。連続実行の前に、いつでも停止できることを確認します。

## 実験と計測

開始位置と向きをテープでそろえ、同じプログラムを複数回実行します。終了位置、向き、実行時間、電源状態、床の条件を記録します。位置がずれた試行も残し、平均だけでなく散らばりを見ます。

## 結果の整理と考察

軌跡を紙に描き、指令した動作との対応を説明します。左右の指令を調整して直進しても、荷物や床を変えたときに維持できるとは限りません。調整した条件と使える範囲を記録します。

## 課題

- **入門**：前進・停止・旋回を組み合わせ、各動作の左右指令を説明する。
- **基本**：同じ動作を繰り返し、停止位置のばらつきを記録する。
- **発展**：床や荷物を一つだけ変え、時間だけの操作で位置がずれる理由を調べる。

**確認問題**：右側が左側より前へ速く進むとき、車体はどちらを向きますか。**考え方**：理想化した左右駆動では左へ向きます。車輪・床の滑りがあれば、実際の曲がり方は測って確認します。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 前進でその場を回る | 電源を切り、左右の正方向と配線を確認 |
| 繰り返し回数が違う | どのブロックが繰り返しの範囲に入るか確認 |
| 走行ごとに軌跡が違う | 開始姿勢、床、電池、固定、左右の抵抗を比較 |
