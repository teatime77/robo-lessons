# 第5章　四輪車の加速・等速運動・減速を調べよう

## 問いと到達目標

走り始めから止まるまで、車はどのように速さを変えるでしょうか。時間ごとの位置を測り、加速・近似的な等速運動・減速をグラフから説明します。

## 前提知識と関連する章

{ref}`visual-vehicle-control` の前進と停止を使います。基本課題では時間と長さを測り、割り算で区間の平均速度を求めます。量と単位は {ref}`notation-conventions` に従います。

## 必要な部品・工具

四輪車、距離目盛、時計または動画撮影機器、固定用の台、記録用紙を使います。カメラはコースへなるべく正対させ、車体の同じ目印を追います。実機の確認は {ref}`practice-readiness` に従います。

## 学ぶこと

### 等しい時間の移動を比べる

同じ時間間隔で位置を記録すると、位置の間隔が広がる区間では速さが増し、ほぼ等しい区間では速さがほぼ一定、狭くなる区間では速さが減っています。観察で分かる範囲と測定の細かさを合わせて説明します。

位置を $x_k$、時刻を $t_k$ とすると、区間の平均速度は次の値です。

$$
\bar v_k=\frac{x_{k+1}-x_k}{t_{k+1}-t_k}
$$

これは区間全体の平均であり、区間内のすべての瞬間で同じ速度だったことは意味しません。位置–時間グラフの傾きが速度と関係し、傾きの変化が加速度の入口になります。

### 指令と運動を分ける

PWMを一定にしても、発進直後には速度が変化します。電源や負荷の変動もあり、一定指令を「等速」と呼ぶだけでは不十分です。位置の増え方を測り、測定精度の範囲でほぼ一定と判断できた区間を近似的な等速運動として扱います。

停止指令の後も、慣性やドライバーの停止方式によって進むことがあります。入力の変化と運動の変化には時間差があるため、指令時刻も記録します。

## 予想

指令を急に与える場合と少しずつ増やす場合で、位置の並びや停止までの時間はどう変わるか、予想のグラフを描きます。

## 工作・配線・プログラミング

1. 直線コースに原点と前向きの座標軸を決め、目盛を置きます。
2. 一定指令で前進して停止する動作を作り、指令と停止の時刻を記録できるようにします。
3. 撮影または観測を開始し、車体の目印を一定の時間間隔で読み取ります。
4. 指令を段階的に増減する動作と比較します。最初は条件を一つずつ変えます。

## 実験と計測

| 記録する列 | 単位・意味 |
| --- | --- |
| 時刻 $t_k$ | s。動画ならフレーム時刻を確認 |
| 位置 $x_k$ | m。車体の同じ目印の位置 |
| 区間の平均速度 $\bar v_k$ | m/s。位置差と時間差から計算 |
| 指令状態 | 発進、一定指令、停止など |

動画のフレーム数から時間を求める際は、一定フレーム間隔かを確認します。人のストップウォッチ操作には反応時間の影響があります。

## 結果の整理と考察

位置–時間と平均速度–時間のグラフを作り、発進・定常的な走行・停止を区別します。区間の平均速度は区間中央の時刻へ置く方法など、表示方法を明記します。細かな振動が本当の動きか、目盛の読み取り誤差かも考えます。

## 課題

- **入門**：同じ時間ごとの位置を点で描き、速さの変化を説明する。
- **基本**：区間の平均速度を計算し、ほぼ一定の区間を根拠とともに選ぶ。
- **発展**：速度の変化から加速度を近似し、測定間隔による違いを調べる。

**確認問題**：位置–時間グラフが水平な区間で、車は等速で進んでいますか。**考え方**：位置が変わらないので速度は0です。斜めの直線なら、一定の非零速度を表すモデルになります。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 読み取る位置がずれる | 車体の目印、撮影方向、目盛と車体の高さを確認 |
| 速度が大きく跳ねる | 時刻の並び、単位、読み取り誤差、時間間隔を確認 |
| 停止後も進む | 停止方式を確認し、走行範囲と測定時間を延長 |
