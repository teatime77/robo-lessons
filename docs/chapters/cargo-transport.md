# 第12章　荷物を運ぶロボットを作ろう

## 問いと到達目標

空の車でできた動作は、荷物を載せても同じようにできるでしょうか。運搬の一連の動作を状態で整理し、荷物が走行、停止、電流へ与える影響を比較します。

## 前提知識と関連する章

{ref}`four-wheel-assembly` の固定と重心、{ref}`speed-measurement` の記録、{ref}`distance-stop` の停止制御を使います。基本では質量と測定条件、発展では仕事とエネルギーを扱います。

## 必要な部品・工具

四輪車、荷台、固定できる軽い荷物、質量計、距離目盛を使います。電流を測る場合は適合する測定器と接続を確認します。車体、モーター、ドライバーの許容条件は {ref}`hardware-specifications`、実施前の確認は {ref}`practice-readiness` に従います。

## 学ぶこと

### 負荷・慣性・摩擦

荷物によって全体の質量が増えると、同じ加速度に必要な力が増えます。荷重の分布やタイヤの変形、摩擦も変わる場合があります。重いから必ず一定の割合で遅くなるとは言えず、電源・機構・制御と合わせて調べます。

荷物の位置は重心と安定性にも影響します。比較実験では質量だけを変え、位置と固定をなるべくそろえます。荷物が移動した試行は、条件が変わったことを記録します。

### 仕事と電気エネルギー

一定の力 $F$ が移動方向に働き、距離 $d$ 動く理想化では仕事は $W=Fd$ です。荷物の重力 $mg$ を、水平移動に対する駆動力とそのまま置き換えません。重力による位置エネルギーの変化は高さの変化に関係します。

電気側の瞬時の供給電力は、同じ供給点で測った電圧・電流による $P=VI$ です。時間で積み上げた供給エネルギーには、機械的な仕事だけでなく熱や制御回路の消費も含まれます。電流一つの値だけで運搬効率は決まりません。

### 動作を状態で表す

「待機→積載確認→移動→減速→停止→荷下ろし確認」という状態を考えます。状態ごとにすることと、次へ進む条件を決めます。異常・通信断は停止へつなげます。積載確認は最初は人の操作でよく、自動検出は追加の実装課題です。

## 予想

荷物を増やすと、発進時間、走行速度、停止位置、電流はどう変わるかを別々に予想します。

## 工作・配線・プログラミング

1. 荷台と固定方法を確認し、許容範囲内の荷物から始めます。
2. 状態、各状態の左右指令、遷移条件を紙の表にします。
3. 荷物なしで一連の動作を確認し、停止状態を保持します。
4. 荷物を固定して同じ動作を試し、目標への到達を実測します。
5. 質量を一段階ずつ変えます。動かない、異常な発熱、荷崩れがあれば中止します。

## 実験と計測

記録する条件は荷物と車体の質量、荷物位置、床、電源状態、指令と制御方式です。結果は到達時間、速度、停止誤差、運搬成功の回数を残します。電流・電圧は測定点と時刻をそろえ、測定できない場合に値を推測しません。

## 結果の整理と考察

成功を「荷物が目的地に届く」「落とさない」「範囲内で停止する」のように分けて評価します。速度が変わっても距離制御で止まれる場合と、荷物で停止誤差が増える場合を比べます。

## 課題

- **入門**：荷物を固定して運び、待機・移動・停止を説明する。
- **基本**：質量を変え、到達時間と停止誤差の比較表を作る。
- **発展**：供給電力の時間変化を記録し、運搬時間とエネルギーの関係を調べる。

**確認問題**：水平に荷物を運んだとき、仕事を常に $mgd$ と計算できますか。**考え方**：重力は鉛直方向なので、そのまま水平の駆動力には使えません。移動方向の力と高さの変化を分けて考えます。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 荷物がずれる | 電源を切り、固定と重心を確認 |
| 発進できない・発熱する | 試験を中止し、荷重、定格、軸抵抗を確認 |
| 状態が先へ進まない | 遷移条件、距離更新、時間超過、確認操作を調べる |
