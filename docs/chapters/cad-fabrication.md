# 第14章　CADと3Dプリンタで部品を作ろう

## 問いと到達目標

センサを狙った位置に固定する部品を、どう設計すればよいでしょうか。測定からCAD、製作、組立、再測定へ進み、設計寸法と実物の違いを説明します。

## 前提知識と関連する章

{ref}`four-wheel-assembly` の固定、{ref}`line-tracing` の取付高さ、{ref}`gears-pulleys` の機構を使います。基本では長さ・角度・立体の見方を前提にします。

## 必要な部品・工具

取付対象のセンサ、車体、定規・ノギス、CADを使うPC、3Dプリンタ、適合する材料、ねじ類を使います。CAD製品、プリンタ、材料、加工条件は未選定です。加熱部と可動部の操作は機器の手順に従い、指導者と確認します。

## 学ぶこと

### 要求を寸法へ変える

「センサを固定する」だけでは形が決まりません。取付高さ、向き、ねじ穴、導線を通す空間、調整できる範囲を要求として書きます。既存部品の寸法を測り、測った場所と基準面をスケッチへ示します。

CADでは平面のスケッチを寸法と関係で定義し、押し出し等で立体にします。寸法を後から変えやすくすると、実験結果に応じた改良ができます。見た目だけで形を合わせず、部品と接する面を基準にします。

### 公差とはめ合い

設計寸法と完成寸法には差が出ます。公差は許容する寸法範囲、すき間は組立のための間隔です。穴と軸を同じ数値にしただけでは、組み立てられるとは限りません。

プリンタの材料、積層方向、造形条件によって寸法や強度は変わります。どの機器にも共通する補正量を仮定せず、小さな試験片で測って決めます。薄い部品やねじ部は、荷重方向と層の向きも考えます。

## 予想

穴と軸を同じ寸法で設計したら入るでしょうか。厚くする、リブを付ける、積層方向を変えると、固定しやすさや製作時間はどう変わるか考えます。

## 工作・配線・プログラミング

1. 取付位置と必要な調整範囲を決め、部品を測ります。
2. 寸法入りのスケッチを作り、CADで最小限の取付具を設計します。
3. 穴・すき間の試験片を作り、実機の寸法差を確認します。
4. 確認した造形条件で製作し、完成品を測ってから組み立てます。
5. センサの高さや向きが変わる場合は、校正と走行実験をやり直します。

元のCADファイルと公開用のSTL等を保存し、設計版、材料、造形設定を記録します。電源を切って取付作業を行います。

## 実験と計測

| 比較する量 | 記録 |
| --- | --- |
| 穴径、厚さ、取付高さ | 設計値、完成品の実測、測定場所 |
| 組立の状態 | 入る、緩い、干渉する、調整可能等 |
| センサの実験結果 | 取付変更前後の校正と走行 |

完成寸法との差は「実測−設計」と定義します。測定器の分解能と読み方も記録します。

## 結果の整理と考察

形の変更、造形条件の変更、センサ校正の変更を分けて評価します。割れた部品は無理に再使用せず、破損箇所と荷重方向から改良点を考えます。造形できたことと実習で安全に使えることは別です。

## 課題

- **入門**：寸法を測り、取付具の役割をスケッチで説明する。
- **基本**：設計値と完成寸法の差を記録し、穴やすき間を修正する。
- **発展**：形状と積層方向を変え、材料量・製作時間・固定性を比較する。

**確認問題**：STLだけを残せば、後から穴径を簡単に変更できますか。**考え方**：STLは形の表面を表す配布形式で、寸法や設計手順が残らない場合があります。編集元のCADも保存します。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 穴にねじが入らない | 単位、出力倍率、完成径、試験片の結果を確認 |
| 取付後にセンサ値が変わる | 高さと向きを測り、再校正 |
| 部品が割れる・干渉する | 使用を止め、荷重方向、厚さ、逃げ、固定を見直す |
