# 第1章　電池とスイッチでモーターとLEDを動かそう

## 問いと到達目標

電池の電気は、どのようにつなぐと光や動きになるでしょうか。DCモーターを回す回路と、スイッチでLEDを点灯する回路を別々に作り、電源・負荷・導線の役割を説明します。閉じた回路をたどり、極性を確認してから操作できることが目標です。

## 前提知識と関連する章

プログラミングの経験は不要です。電池の正極・負極を見分け、工具を扱う際に指導者と確認できれば始められます。最初に {ref}`practice-readiness` と {ref}`hardware-specifications` を読みます。

## 必要な部品・工具

単三電池と電池ボックス、適合するDCモーター、LED、電流制限抵抗、スイッチ、導線、接続用具、テスターを用意します。電池の種類・個数、モーター定格、LED仕様、抵抗値と電力定格は要確認です。単三という形状だけでは供給電圧や使用条件は決まりません。

## 学ぶこと

### 電気が流れる道とエネルギー

電源から負荷へ行き、電源へ戻る道がつながると回路が閉じます。スイッチはこの道を開閉する部品です。電流は回路を流れる電荷の量を表し、負荷で「使い切ってなくなる」ものではありません。電池のエネルギーがモーターの運動やLEDの光、熱などへ変わります。

電圧は電流と別の量です。電池が接続されていても、スイッチを開いている回路には通常の動作電流が流れません。入門では回路を指でたどり、基本ではテスターで電圧を確認します。

### モーターとLEDの違い

一般的なブラシ付きDCモーターは、電源の向きを変えると回転方向が変わります。保護回路付き等の製品は先に仕様を確認します。LEDには極性があり、逆向きにする実験は耐逆電圧を確認せずに行いません。モーターと同じ方法で向きを試さないことが大切です。

LEDの電流を抑える抵抗は、供給電圧 $V_s$、順方向電圧 $V_f$、設定電流 $I$ から、近似的に $R=(V_s-V_f)/I$ と考えられます。実際には電池電圧の変動とLEDの仕様範囲を確認し、抵抗の発熱 $P=I^2R$ も検討します。数式による選定は基本・発展で扱います。

## 予想

スイッチの位置を回路の途中で変えても開閉できるか、モーターの電源極性を変えると何が変わるかを絵にします。LEDにはどの部分に抵抗を入れる必要があるかも予想します。

## 工作・配線・プログラミング

1. 型番と定格を確認し、電源・スイッチ・負荷を示す回路図を紙に描きます。
2. 電池を外してモーター回路を組み、導線が軸に触れないように固定します。
3. 指導者と配線を照合し、短時間通電して回転と停止を確認します。軸を手で止めません。
4. 電源を外し、モーターの仕様が許す場合に極性を入れ替えて、方向を比べます。
5. 別のLED回路を、確認済み抵抗と正しい極性で組みます。スイッチで点灯・消灯を確認します。

この章ではマイコンを使わず、人がスイッチを操作します。

## 実験と計測

| 変える条件 | 観察・測定 | そろえる条件 |
| --- | --- | --- |
| スイッチの開閉 | モーターの動作、LEDの点灯 | 同じ回路と電池 |
| モーターの電源極性 | 回転方向 | 同じモーター、負荷なし |
| 通電前と通電中 | 電源電圧、発熱の有無 | 同じ測定端子とレンジ |

測定値は実験後に記入します。電圧測定は対象の両端で行い、電流測定の接続と混同しません。

## 結果の整理と考察

完成した回路に電流の道を描き、開閉で変化した部分を説明します。動かなかった場合も、電池・接続・負荷のどこを調べたか記録します。光の明るさや回転の勢いだけでは電流値は分かりません。

## 課題

- **入門**：点灯と消灯を実演し、スイッチの働きを絵で説明する。
- **基本**：モーターとLEDの回路図を描き、極性と抵抗の役割を説明する。
- **発展**：確認済み仕様から抵抗の候補と発熱を計算し、選定理由を示す。

**確認問題**：LEDが光らないとき、すぐに抵抗を外してよいでしょうか。**考え方**：電源を切り、極性・接続・電池を先に確認します。抵抗を外すと許容電流を超える可能性があるため、明るくする対処には使いません。

## トラブル対処

| 症状 | 電源を切って確認すること |
| --- | --- |
| モーターが回らない | 電池、スイッチ、接続、軸の固定、定格との適合 |
| LEDが光らない | 極性、抵抗、導線、接点。LEDの逆向き通電を繰り返さない |
| 発熱・異臭がある | 通電を中止し、短絡、抵抗定格、モーター拘束を調べる |
