# 第3章　四輪車を組み立てよう

## 問いと到達目標

モーターが回るだけでは、車はうまく走りません。どのように部品を固定すれば、回転を移動へ伝えられるでしょうか。四輪車を組み、軸、摩擦、重心、左右駆動の役割を説明します。

## 前提知識と関連する章

{ref}`battery-motor-led` の配線確認と {ref}`visual-motor-control` の停止操作を使います。長さを測り、左右を見分ける経験が必要です。実機の条件は {ref}`practice-readiness` で確認します。

## 必要な部品・工具

車体、車輪、軸・軸受、モーターと取付具、ねじ類、電池ボックス、ESP32、ドライバー、配線固定材、ドライバー工具、定規を用意します。モーターの個数、車輪径、駆動の接続、部品寸法は {ref}`hardware-specifications` で確定します。

## 学ぶこと

### 軸・固定・摩擦

車輪の中心を通る軸が傾くと、車輪が車体へこすれたり、進む向きがずれたりします。固定すべき箇所と自由に回る箇所を区別します。ねじを強く締めれば必ず良くなるわけではなく、回転部を締め付けると抵抗が増えます。

摩擦は走行を妨げる一方、車輪が床を押して進むためにも必要です。軸の摩擦と車輪・床の摩擦は場所と役割が違います。組み立てでは、不要な接触を減らし、床との接触を安定させます。

### 重心と配置

重い部品をどこに置くかで、車輪にかかる荷重や転倒しやすさが変わります。重心は重さの分布をまとめて表す位置です。入門では部品配置を比べ、発展では重心の高さと支持する範囲の関係を考えます。電池を高い位置に載せる場合は、倒れやすさを確認します。

### 左右独立駆動

この教材では左右の駆動を独立に制御します。左右の進み方の差で向きが変わるため、前輪を操舵する車とは仕組みが違います。四輪の旋回では床との横滑りが関わる場合があり、理想的な差動二輪モデルをそのまま正確な実機モデルとは扱いません。

## 予想

電池を前・後ろ・低い位置へ置くと、安定性はどう変わるでしょうか。車輪が車体に触れる場合と離れている場合の違いも予想します。

## 工作・配線・プログラミング

1. 部品を並べ、車体の前向きと左右、電源切断箇所を決めます。
2. 車輪とモーターを固定し、電源を入れずに回転や接触を確認します。減速機付き軸を無理に手で回しません。
3. 電池と基板を固定し、荷重が偏らない配置を検討します。
4. 導線を回転部から離して固定し、確認済み配線図と照合します。
5. 車輪を浮かせ、低い指令で左右それぞれの前進方向と停止を確認します。

## 実験と計測

車体寸法、車輪径、左右の車輪間隔、部品配置を記録します。電源を切った状態で車輪の接触・引っかかりを点検し、配置を変更したときの傾きや固定の状態を比較します。移動試験は床の平らな範囲で少しずつ行います。

## 結果の整理と考察

完成写真またはスケッチに、回る箇所、固定する箇所、電源、配線経路を示します。「走れた」だけでなく、車輪に触れる配線がないか、部品が緩まないかを成果として確認します。

## 課題

- **入門**：四輪車を組み、車輪と配線が接触しないことを説明する。
- **基本**：寸法と部品配置を記録し、配置変更の前後を比較する。
- **発展**：重心が支持範囲を外れると倒れる理由を、重力と回転の関係で考える。

**確認問題**：摩擦をすべて小さくすると、車は必ず走りやすくなりますか。**考え方**：軸の不要な摩擦は減らしたい一方、車輪と床の摩擦が小さすぎると滑ります。どの場所の摩擦かを指定する必要があります。

## トラブル対処

| 症状 | 電源を切って確認すること |
| --- | --- |
| 車輪が引っかかる | 車体との接触、軸の傾き、締め付け |
| 部品がずれる | 固定方法、ねじの緩み、荷重の偏り |
| 左右で前進方向が違う | モーターの取付向きと指令の符号 |
