# 第8章　線に沿って走ろう

## 問いと到達目標

床の線を頼りに、どのように曲がる方向を決めるでしょうか。ラインセンサを校正し、測定値と左右の駆動を結び付け、線を見失った場合も含むプログラムを作ります。

## 前提知識と関連する章

{ref}`obstacle-stop` のしきい値と条件分岐、{ref}`visual-vehicle-control` の左右操作を使います。実施条件と定格は {ref}`practice-readiness` と {ref}`hardware-specifications` に従います。

## 必要な部品・工具

四輪車、反射型ラインセンサ、取付具、床面と対照的な色のテープ、定規、記録用具を使います。センサの個数、出力形式、取付高さ、電源と信号レベルは選定後に確定します。

## 学ぶこと

### 校正してから「黒・白」を判断する

反射型センサは、出した光がどれだけ戻るかを調べます。黒と白の数値の大小は回路や出力形式によって違うため、「黒なら小さい」と決め付けません。同じ取付高さで線上と床上を測り、値の分布と重なりを見ます。

校正とは、実際の条件で測定値の意味を確かめることです。照明や高さが変われば校正結果も変わる場合があります。しきい値を一つの測定だけで決めず、複数の値から判断の余裕を検討します。

### センサの配置と制御の対応

複数センサを使う場合は、左右のどのセンサが線を見たかで、線が車体のどちらにあるかを判断します。線が左にあると分かったなら、左側の進み方を小さくする等の操作で左へ寄せます。実際の配置と判定を紙の表にします。

「両方とも床」には、線がセンサの間にある場合と、完全に線を見失った場合があり得ます。「両方とも線」も、太い線や交差点の可能性があります。センサの配置と線幅を確認し、曖昧な状態を自動的に直進と決めません。

## 予想

走る速さ、線の曲率、照明を変えると、線を追いやすさはどう変わるでしょうか。センサを車体前方へ置く効果も予想します。

## 工作・配線・プログラミング

1. センサを固定し、左右の番号と取付位置を記録します。
2. 車を止めたまま床と線の値を集め、しきい値を決めます。
3. 線が左・中央・右にあるときの判定と指令を、実際の配置に合わせて表にします。
4. 次の疑似コードをブロックへ対応させます。

```text
センサを繰り返し読む
線の位置を判断できる → 対応する左右指令を出す
線を見失った・判断できない → 停止し、状態を記録する
```

5. 直線から試し、次に緩い曲線へ進みます。見失った後の探索動作は停止を確認してから発展課題で扱います。

## 実験と計測

線と床の値、取付高さ、照明、走行指令、コース形状、完走・停止の回数を記録します。失敗した場所を地図に示し、急な曲線や照明の違いと対応させます。

## 結果の整理と考察

左右へ蛇行するなら、方向を大きく切り替えすぎる、読み取り周期が遅い、速さが高すぎる等の可能性を比較します。コースを一周できたことと、別の床でも動くことは別の評価です。

## 課題

- **入門**：手で車を線の左右へ動かし、判定と指令を説明する。
- **基本**：校正の記録と判断表を作り、照明変更後に再評価する。
- **発展**：線からのずれに応じて左右指令を段階的に変え、蛇行を比べる。

**確認問題**：しきい値を一度決めれば、センサの高さを変えても同じ判定でよいですか。**考え方**：高さで反射光の量が変わるため、再校正して分布を確認します。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 線と床を区別できない | 高さ、照明、色、しきい値、出力方向を確認 |
| 線から離れる方向に曲がる | 左右センサ番号、モーター方向、判断表を確認 |
| 線を失って走り続ける | 曖昧・無効状態を停止へつなぐ処理を確認 |
