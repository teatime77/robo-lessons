# 第19章　サーボで物を動かそう

## 問いと到達目標

回転し続けるモーターから、角度を指定して物を動かす機構へ進みます。1軸のサーボ機構とグリッパーを作り、角度・てこ・トルク・保持の再現性を説明します。

## 前提知識と関連する章

{ref}`four-wheel-assembly` の固定と重心、{ref}`gears-pulleys` のトルク、{ref}`text-programming` の指令と状態を使います。基本では角度と力の作用点を扱います。

## 必要な部品・工具

位置制御型サーボ、適合するホーン、台、グリッパー、軽い対象物、確認済み電源、角度目盛を使います。連続回転型とは動作が違います。型番、信号条件、可動範囲、電源・起動・拘束電流、負荷条件は {ref}`hardware-specifications` で確認します。

## 学ぶこと

### 指令角度と実角度

位置制御型サーボでは、指令に応じて内部の制御機構が角度を調整します。しかし指令がそのまま高精度の実角度になるとは限らず、負荷やがたつきが影響します。電源切断時に保持できるかも機種と機構に依存します。

サーボの指令角度、ホーンの向き、機構の関節角を分けます。取付時のずれを補正し、実際の角度を測って対応を確認します。市販サーボの表示範囲を、そのまま完成機構の安全な可動範囲とは扱いません。

### てことトルク

回転軸から離れた位置に力が働くと、回転させようとする作用が生じます。軸からの距離ベクトルと力の向きが関係します。力に垂直な距離を $\ell_\perp$ とすると、トルクの大きさは $\tau=F\ell_\perp$ です。

水平に伸ばした腕が質量 $m$ を支える理想例では、荷物によるトルクは $mg\ell$ です。腕自身の質量も考慮します。物を持つ位置を遠くすると負担が増すため、軽い物から始めます。動かすときの慣性も静止時の計算とは別です。

### つかむ力と機構

グリッパーは摩擦や形状で物を保持します。握る力を強くすれば必ず良いわけではなく、対象物の変形やサーボの負担が増えます。指先の材質、開閉範囲、物の位置をそろえて比較します。

## 予想

同じ物を軸の近くと遠くで支えると、保持しやすさはどう変わるでしょうか。同じ角度へ左右から近づけた場合の違いも予想します。

## 工作・配線・プログラミング

1. 確認済みの電源と信号条件で、機構を付けずに狭い角度範囲を確認します。
2. 電源を切り、ホーンと機構を固定して、干渉・挟み込み箇所を確認します。
3. 指令角度と実角度の対応、機構の可動範囲を測ります。
4. 小さな角度差で段階的に動かし、低い負荷で停止と保持を確認します。
5. 軽い物をつかみ、保持時間と位置をそろえて比較します。

{ref}`practice-readiness` に従い、サーボへGPIOから電力を供給しません。機械的な限界まで押し続けず、停止後や電源切断時に落下しない支えを用意します。

## 実験と計測

指令角度、実角度、接近方向、対象物の質量、軸からの位置、保持できた時間、発熱・異常を記録します。電流は測定器の条件が確認できた場合に測ります。定格超過による限界試験は行いません。

## 結果の整理と考察

指令と実角度の差を、無負荷と負荷ありで比較します。がたつき、弾性変形、電源の影響を分けて考えます。物を落とさなかった一回だけで保持性能を判断せず、再現性を確認します。

## 課題

- **入門**：角度指令で開閉し、動作範囲を説明する。
- **基本**：指令と実角度を表にし、物を持つ位置による違いを調べる。
- **発展**：荷物と腕自身の重力トルクを見積もり、確認済み定格と比較する。

**確認問題**：同じ質量を、軸から2倍遠い位置で水平に支えると、荷物によるトルクはどうなりますか。**考え方**：静止した理想例では2倍です。これは腕自身の重量や動的な負荷を含まない比較です。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 震える・保持できない | 電源を切り、負荷、電源容量、固定、指令範囲を確認 |
| 指令と向きが違う | ホーン取付、ゼロ位置、角度変換を確認 |
| 端で音・発熱が出る | 動作を中止し、干渉と可動範囲を見直す |
