# 第17章　傾きと回転を測ろう

## 問いと到達目標

車輪が回っていなくても、車体の傾きや向きの変化は測れるでしょうか。加速度センサとジャイロの違いを調べ、校正・軸・時間による誤差を説明します。

## 前提知識と関連する章

{ref}`wheel-motion` の加速度、{ref}`speed-measurement` の時系列、{ref}`speed-feedback` の遅れを使います。基本では座標軸、発展では積分と三角関数を扱います。

## 必要な部品・工具

IMU、ESP32、固定具、角度を確認できる台、記録環境を使います。測定範囲、単位、通信、部品固有の軸を {ref}`hardware-specifications` で確認します。車体座標は {ref}`notation-conventions` に合わせます。

## 学ぶこと

### 加速度センサとジャイロ

加速度センサの出力を、そのまま位置の2回微分とは扱いません。理想的な出力は比力に対応し、静止中も支持力に対応する成分が現れます。姿勢推定では、その成分を重力方向と関連付けます。単位換算、符号、軸の意味は実機の仕様で確認します。

ジャイロは角速度を測ります。角度そのものを直接測るわけではなく、時刻ごとの角速度を積み重ねて角度変化を推定します。部品の出力単位が度毎秒なら、計算に使うrad/sへ変換します。

### 静止・傾斜・並進加速を分ける

十分に静止しているときは、重力に対応する方向から傾きを推定できます。車が加速したり旋回したりすると、その成分も重なり、重力方向だけを使った傾き推定がずれる場合があります。[Analog Devicesの傾き計測資料](https://www.analog.com/en/resources/app-notes/an-1057.html)。

重力方向だけでは、水平面内でどちらを向いているかという方位は決まりません。加速度とジャイロだけのIMUから、絶対位置や絶対方位がいつも正確に得られるとは考えません。

### 校正とドリフト

静止したときのジャイロの平均をバイアスとして見積もり、差し引いて角度を積分します。単一軸の近似では、$\hat\theta_{k+1}=\hat\theta_k+(\omega_k-\hat b)\Delta t$ です。小さなバイアス誤差も時間とともに角度のずれを増やします。

発展では、ジャイロの短時間の変化と加速度の傾き推定を組み合わせる相補フィルタを考えます。平滑化が遅れを生むこと、並進加速時に傾き推定の信頼度が変わることも扱います。

## 予想

静止、ゆっくり傾ける、水平のまま加速する場合に、各軸の値がどう変わるか予想します。

## 工作・配線・プログラミング

1. IMUの軸と車体の前・左・上を図に描き、固定します。
2. 静止状態で生の値と換算後の値を記録し、単位とバイアスを確認します。
3. 一つの軸だけを回転させ、符号と軸の対応を確認します。
4. 計測時刻を使って単一軸の角度変化を積分します。
5. 車輪による旋回推定と比べ、静止・加速・旋回の記録を分けます。

実施前は {ref}`practice-readiness` に従います。取付変更後は校正と軸変換を再確認します。

## 実験と計測

加速度と角速度の3軸、計測時刻、単位、校正値、取付姿勢を保存します。静止のまま時間を延ばした角度推定と、外から測った回転角を比較します。センサ値から推定した姿勢は、独立した角度の実測と分けます。

## 結果の整理と考察

ノイズ、一定のずれ、時間とともに増えるずれを区別します。車輪とIMUが一致しない場合は、床の滑り、取付、積分誤差、時刻の対応を調べます。

## 課題

- **入門**：傾ける方向と変化する軸を対応させる。
- **基本**：静止時のバイアスを求め、角度推定の時間変化を記録する。
- **発展**：相補フィルタで傾きを推定し、静止と加速時の違いを説明する。

**確認問題**：静止した車で加速度センサの全軸が0でないのは、必ず故障ですか。**考え方**：静止中でも支持力に対応する成分が出ます。まずセンサが測る量、単位、姿勢を確認します。

## トラブル対処

| 症状 | 確認と対処 |
| --- | --- |
| 軸や符号が違う | 部品座標と車体座標、取付、変換を確認 |
| 静止中に角度が流れる | バイアス、温度、時刻、単位を確認 |
| 加速すると傾きが変わる | 並進加速と姿勢の区別、フィルタの仮定を確認 |
