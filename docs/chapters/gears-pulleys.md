# 第13章　車輪・歯車・プーリーを変えてみよう

## 問いと到達目標

荷物を運びやすくするには、モーターを強くするほかに何ができるでしょうか。車輪径と動力伝達の比を変え、速さ・トルク・損失の関係を説明します。

## 前提知識と関連する章

{ref}`wheel-encoder` の円周と回転、{ref}`cargo-transport` の負荷を使います。基本では比と力、発展では仕事・効率を扱います。

## 必要な部品・工具

適合する車輪、歯車またはプーリーとベルト、取付具、四輪車、定規、軽い荷物を使います。かみ合い、軸径、ベルトの張力、許容トルクと荷重は確認が必要です。回転部を覆い、{ref}`practice-readiness` に従います。

## 学ぶこと

### 車輪径と接線方向の力

滑らない車輪では、角速度 $\omega$ と速さの関係は $v=r\omega$ です。同じ回転速度なら、大きい車輪は1回転で遠くへ進みます。一方、車輪軸のトルク $\tau$ が同じなら、接線方向の力は理想的に $F=\tau/r$ となり、大きい車輪ほど小さくなります。

「大きい車輪なら常に速い」とは言えません。負荷によってモーターの回転速度が変わり、床で滑る場合もあります。回転速度を一定とする計算と、実機の結果を分けます。

### 減速比と動力伝達

減速比を $i=\omega_{\mathrm{in}}/\omega_{\mathrm{out}}$ と定義します。$i>1$ の減速では、出力軸の角速度は $\omega_{\mathrm{out}}=\omega_{\mathrm{in}}/i$ です。動力損失のないモデルなら、出力トルクは入力トルクの $i$ 倍です。

実際の効率を $\eta$ とすれば、定常状態の近似は $\tau_{\mathrm{out}}\approx\eta i\tau_{\mathrm{in}}$ です。減速はエネルギーを増やす仕組みではなく、回転速度とトルクの組合せを変えます。加速中の慣性も単純な定常モデルとは分けます。

歯車では歯数比、滑らないベルトでは有効なプーリー径の比を使います。歯車のかみ合う段数やベルトの掛け方で回転方向が変わるため、比の大きさと向きを別々に確認します。

## 予想

同じモーターに大きな車輪を付けた場合と、減速比を大きくした場合について、空車の速さと荷物を運ぶ能力を別々に予想します。

## 工作・配線・プログラミング

1. 変更前の径・減速比・速度・荷物条件を記録します。
2. 電源を切って一つの部品だけを変更し、接触と固定を確認します。
3. 車輪径または計測軸の減速比が変わったら、エンコーダーの換算も更新します。
4. 車輪を浮かせて低い指令で回転方向を確認します。
5. 同じ床、電源状態、指令で空車と軽い荷物の走行を比較します。定格を超える試験や軸の拘束は行いません。

## 実験と計測

車輪径、歯数・プーリー径、減速比、荷物の質量、回転速度、走行速度、停止位置を記録します。軽い傾斜を使う場合は角度と安全な停止方法を先に確認し、荷物の条件をそろえます。

## 結果の整理と考察

回転速度が同じという仮定の理論値と、負荷を受けた実測値を比較します。遅くなった原因を減速比だけに求めず、軸の摩擦、ベルトの張り、歯車の接触も確認します。

## 課題

- **入門**：車輪1回転で進む距離を比べる。
- **基本**：減速比を定義し、入力・出力の回転速度を計算する。
- **発展**：負荷を変え、理想的な比と実際の速度・供給電力の違いを調べる。

**確認問題**：損失がないと仮定し、減速比を2にすると、トルクと回転速度はどうなりますか。**考え方**：トルクは2倍、回転速度は半分です。両者の積で表す動力は増えません。これは説明用の理想モデルです。

## トラブル対処

| 症状 | 電源を切って確認すること |
| --- | --- |
| 異音・引っかかりがある | 軸の平行、歯車間隔、ベルト張力、固定 |
| 計算距離だけ変になった | 車輪径と測定軸の換算更新 |
| ベルトが滑る | 適合する部品と張力。張りすぎで軸を傷めない |
