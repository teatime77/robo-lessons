# ロボットで学ぶ

電気をつなぎ、プログラムを書き、ロボットを動かす。動きを測り、理由を考え、改良する。

この教材では、四輪車づくりを入口に、電気・プログラミング・数学・物理・設計を少しずつ学びます。同じロボットや実験を、理解に合わせてより深く考えていきます。

## この教材の進め方

各章は「問い → 予想 → 工作・プログラミング → 実験・計測 → 考察 → 発展課題」の順で進めます。１章を１回で終える必要はありません。組み立てや自由制作には、複数回の授業を使います。

- **入門課題**：動かして比べ、言葉や図で説明します。
- **基本課題**：距離・時間・角度などを測り、計算やグラフで説明します。
- **発展課題**：数式でモデルを作り、シミュレーションと実機を比較します。

年齢は目安です。未経験の大人も入門から始められます。高校・大学の数学を使う発展課題は、前提知識を学んでから取り組みます。

| 学習段階 | 主な取り組み | 目次の目安 |
| --- | --- | --- |
| 入門：小学生・初めての人 | 電気の実験、四輪車の組み立て、ブロックで操作 | 第1〜6章 |
| 初級：小学校高学年以上 | センサ、条件分岐、回転数・距離の計測 | 第7〜12章 |
| 中級：中学生以上 | 機構の改良、CAD、テキストによるプログラミング、制御 | 第13〜18章 |
| 発展：高校生以上 | アーム、座標、画像処理、AI、自由制作 | 第19〜24章 |
| 専門：大学生・経験のある人 | 数値計算、動力学、状態推定、倒立振子 | 第25〜28章 |

## 学習を始める前に

- 部品と工具：ESP32、モータードライバー、モーター、LED、抵抗、スイッチ、電池、テスターなど。
- 安全：短絡、電池の極性、モーターの拘束、車輪への巻き込みを確認します。配線を変える前に電源を切ります。
- 電源：単三電池、USB電源、モバイルバッテリー、ACアダプターを、必要な電圧と電流に合わせて使います。
- モーターは適切なドライバーを介して制御します。マイコンのGPIOに直接つなぎません。
- LEDには電流制限用の抵抗を入れます。配線図と部品の定格を確認してから通電します。
- 実験記録：予想、変更した条件、測定結果、気付いたことを残します。

### 第1章　電池とスイッチでモーターとLEDを動かそう

→ {ref}`学習内容・実験・課題 <battery-motor-led>`

**課題：単三電池でDCモーターを回し、スイッチでLEDを点灯する。**

- 学ぶこと：回路、電源、極性、導線、スイッチ、LEDと抵抗。
- 実験：電池の向きを変えたときのモーターの回転方向を比べる。
- 発展：テスターで電圧を測り、LEDとモーターの回路の違いを説明する。

### 第2章　ビジュアルプログラミングでモーターを動かそう

→ {ref}`学習内容・実験・課題 <visual-motor-control>`

**課題：ブロックを並べて、回転・停止・逆回転を指示する。**

- 学ぶこと：マイコン、入力・処理・出力、モータードライバー、順次実行、待ち時間。
- 実験：回転する時間や指令値を変え、動きの違いを観察する。
- 発展：PWMの指令値と回転速度が、必ずしも比例しないことを調べる。

### 第3章　四輪車を組み立てよう

→ {ref}`学習内容・実験・課題 <four-wheel-assembly>`

**課題：車体、モーター、車輪、電池、制御基板を取り付ける。**

- 学ぶこと：軸、固定、摩擦、重心、配線、左右の駆動。
- 実験：車輪が自由に回るか、配線が車輪に触れないかを確認する。
- 発展：重い部品の位置を変え、車体の安定性を比べる。

この教材の基本車体は左右独立駆動とし、左右の速度差で旋回させます。前輪操舵型の四輪車は、別の発展課題として扱います。

### 第4章　ビジュアルプログラミングで四輪車を走らせよう

→ {ref}`学習内容・実験・課題 <visual-vehicle-control>`

**課題：前進・停止・後退・旋回を組み合わせ、コースを走る。**

- 学ぶこと：繰り返し、左右のモーター指令、動作の順序、プログラムの修正。
- 実験：同じプログラムを繰り返し実行し、止まる位置の違いを記録する。
- 発展：直進しにくい理由を、車輪・床・左右のモーターの違いから考える。

### 第5章　四輪車の加速・等速運動・減速を調べよう

→ {ref}`学習内容・実験・課題 <wheel-motion>`

**課題：発進から停止までの動きを変え、時間ごとの位置を測る。**

- 学ぶこと：速い・遅い、速度の変化、加速、等速運動、減速、時間と位置のグラフ。
- 実験：指令値を一定にする場合と、少しずつ増減させる場合を比べる。
- 発展：動画や区間ごとの計測で、実際の速さの変化を確認する。

一定のモーター指令が一定の速度を保証するわけではありません。最初は近似的な等速運動を調べ、正確な速度制御は{ref}`speed-feedback`で学びます。

### 第6章　四輪車の移動距離を計算しよう

→ {ref}`学習内容・実験・課題 <travel-distance>`

**課題：速さと時間から進む距離を予想し、実測値と比べる。**

- 学ぶこと：距離・時間・速さの関係、単位、測定値と予想の差。
- 実験：近似的な等速運動で「距離＝速さ×時間」を使う。
- 発展：速度が変わる運動を短い時間に分け、各区間の移動距離を足す。

高校生以上は、速度と時間のグラフの面積から積分へ進みます。等加速度の式は、その仮定が成立するモデルで扱います。

### 第7章　障害物の前で止まろう

→ {ref}`学習内容・実験・課題 <obstacle-stop>`

**課題：距離センサで障害物を検出し、四輪車を停止させる。**

- 学ぶこと：センサ値、条件分岐、しきい値、停止までの距離。
- 実験：物体の形・材質・向きを変え、距離測定の違いを調べる。
- 発展：速く走るときは、なぜ早めに止まり始める必要があるか考える。

### 第8章　線に沿って走ろう

→ {ref}`学習内容・実験・課題 <line-tracing>`

**課題：ラインセンサを使い、黒い線に沿って進む。**

- 学ぶこと：反射光、センサの校正、条件分岐、繰り返し。
- 実験：床や照明を変え、センサ値と走行の違いを比べる。
- 発展：線を見失ったときの動作を追加する。

### 第9章　車輪の回転数を数えよう

→ {ref}`学習内容・実験・課題 <wheel-encoder>`

**課題：エンコーダーで回転を測り、車輪の円周から移動距離を求める。**

- 学ぶこと：円周、回転数、パルス、分解能、回転方向。
- 実験：車輪を決まった回数だけ回し、パルス数との関係を調べる。
- 発展：車輪の滑りがあると、計算した距離と実際の距離が異なることを確認する。

### 第10章　測った速度をグラフにしよう

→ {ref}`学習内容・実験・課題 <speed-measurement>`

**課題：一定時間ごとの回転量から速度を求め、ブラウザに表示する。**

- 学ぶこと：変数、測定間隔、データ記録、グラフ、差分。
- 実験：{ref}`wheel-motion`の加速・減速を、エンコーダーの計測で調べ直す。
- 発展：測定間隔を変え、細かさとばらつきの関係を調べる。

### 第11章　指定した距離で止まろう

→ {ref}`学習内容・実験・課題 <distance-stop>`

**課題：回転量を読みながら、目標の距離に近づいたら減速・停止する。**

- 学ぶこと：目標値、実測値、誤差、停止条件、フィードバックの入口。
- 実験：時間だけで止める方法と、距離を測って止める方法を比べる。
- 発展：停止後の行き過ぎを減らすため、減速の開始位置を調整する。

### 第12章　荷物を運ぶロボットを作ろう

→ {ref}`学習内容・実験・課題 <cargo-transport>`

**課題：荷物を載せ、目的地まで運んで停止する。**

- 学ぶこと：負荷、摩擦、仕事、電流、複数の動作の組み合わせ。
- 実験：荷物の重さを変え、速さ・停止位置・消費電流を比べる。
- 発展：待機・移動・停止などの状態を分けてプログラムを整理する。

- 実験：同じ条件で速さを比べ、軽い負荷を使って力の違いを調べる。

- 学ぶこと：寸法、ノギス、スケッチ、3D CAD、印刷、組み立て、公差。
- 実験：設計寸法と印刷後の寸法を比べ、取り付け具を修正する。

### 第15章　ブロックからテキストのプログラムへ進もう

→ {ref}`学習内容・実験・課題 <text-programming>`

**課題：すでに作った車の動作を、JavaScript・TypeScriptまたはPythonで表す。**

- 学ぶこと：変数、条件分岐、繰り返し、関数、配列、デバッグ。
- 実験：同じ動作をブロックとテキストで実行し、対応を確認する。
- 発展：ブラウザ側とESP32側の役割を分け、C／C++のプログラムを読む。

言語は目的に合わせて選びます。この章ですべての言語を習得する必要はありません。

### 第16章　荷物が変わっても同じ速度で走ろう

→ {ref}`学習内容・実験・課題 <speed-feedback>`

**課題：エンコーダーの速度を使い、目標速度を保つ制御を作る。**

- 学ぶこと：開ループと閉ループ、比例制御、PI・PID制御、制御周期。
- 実験：荷物や床の条件を変え、制御なしの場合と比べる。
- 発展：振動、行き過ぎ、指令の上限を調べ、制御係数を調整する。

### 第17章　傾きと回転を測ろう

→ {ref}`学習内容・実験・課題 <imu-orientation>`

**課題：IMUで傾きや旋回を調べ、車輪の計測結果と比べる。**

- 学ぶこと：加速度、角速度、座標軸、重力、校正、ノイズ。
- 実験：静止・傾斜・加速で値がどう変わるか調べる。
- 発展：ジャイロの積分による角度推定と、時間とともに増える誤差を観察する。

### 第18章　目的地まで自律走行しよう

→ {ref}`学習内容・実験・課題 <autonomous-navigation>`

**課題：距離、方向、障害物の情報を組み合わせ、目的地へ進む。**

- 学ぶこと：座標、旋回、経路、状態遷移、位置推定。
- 実験：距離と旋回を組み合わせたコースを走り、到着位置を測る。
- 発展：差動二輪ロボットと四輪車を比べ、滑りによる旋回誤差を調べる。

## 数学・物理の教材へ進む

この教材では、実験を理解するための数学・物理を各章で紹介します。体系的な定義、証明、演習は、数学・物理の教材で深めます。

| ロボットでの体験 | 次に学ぶ内容 | さらに進む分野 |
| --- | --- | --- |
| 距離・速度・加速度の計測 | 関数、微分・積分、微分方程式 | 力学、解析力学 |
| アームと座標 | 三角関数、ベクトル、行列、座標変換 | 多変数微積分、ロボットの運動学 |
| モーター・回路・磁石 | 回路、電磁誘導、電磁場 | 電磁気学、特殊相対論 |
| 振動・音・制御応答 | 波動、複素数、フーリエ解析 | 電磁波、量子力学 |
| センサのノイズと学習 | 確率・統計、推定、熱・統計力学 | 統計物理、機械学習 |
| エネルギーと保存量 | 解析力学、対称性、ハミルトン形式 | 量子力学、場の理論、素粒子論 |

相対論・量子力学・素粒子論へは、必要な数学と物理を補いながら進みます。ロボット実習だけで、これらの分野全体を扱うものではありません。
